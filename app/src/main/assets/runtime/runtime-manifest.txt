Run tools/fetch-runtime.sh from the project root to download and verify them again.

Notes
-----
- proot and busybox are aarch64 (arm64) binaries; this extension only supports arm64 devices.
- targetSdk is 28 on purpose: Android 10+ blocks exec of app-data binaries for API 29+ apps.
